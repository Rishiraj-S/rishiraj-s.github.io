Player Scouting Dashboard

Player Scouting Dashboard is an interactive data analytics dashboard built for modern football recruitment. The platform enables scouts and analysts to upload custom datasets, filter players across multiple dimensions including position, age, market value, and performance metrics, and conduct in-depth comparative analysis. Features include dynamic radar chart visualizations powered by Plotly, a comprehensive player browser with detailed modal views, side-by-side player comparison tools, and a personalized favorites system. Built with Streamlit and Python, the platform supports flexible data ingestion via CSV/Excel uploads or Google Drive integration, making it a versatile tool for data-driven player evaluation and scouting workflows.
